==============================================================================

Agar admin tidak nakal melakukan rekayasa penjualan atau order.
jika orderan dibuat melalui marketplace maka Admin tidak dapat melakukan edit.
Atur juga agar admin bisa menolak orderan jadi status nya pending, diterima, ditolak, dibatalkan, selesai. 
Jika admin menolak maka buyer akan mendapatkan notifikasi bahwa orderan ditolak oleh admin. 
Jika admin membatalkan maka buyer akan mendapatkan notifikasi bahwa orderan dibatalkan oleh admin. 
Jika admin menyelesaikan maka buyer akan mendapatkan notifikasi bahwa orderan selesai oleh admin.

Hapus aksi yang ada di kolom pada tabel sebelumnya karen sudah ada tombol action special sebelummnya.
Pilih kolom terapkan juga untuk menampilkan aksi kolom.
ubah status pesanan langsung aja diubah melalui kolom status pesanan agar lebih cepat dan efisien.

melakukan edit biaya bahan baku dan product akan menjadi sebuah laporan di HPP dan akan menampilkan riwayat perubahan biaya bahan baku dan product.

Tampilan active nonactive menjadi sebuah toggle switch agar lebih mudah diakses dan tidak memakan banyak tempat. 
Jika nonakif maka 1 baris data akan gelap.

Khusus manajemen user jika melakukan nonaktif maka akan memberikan sebuah pesan berupa pelanggaran yang dilakukan oleh user tersebut. 
Buyer dapat membaca pelanggaran melalui modal page yang tampil di website buyer
